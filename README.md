# AdvancedGenerationEnemyOnLevel

Учебный проект по Unity/C# — продвинутая генерация врагов.

## Что реализовано
- Система спавнеров, каждый создает свой тип врагов
- Передача зависимостей по цепочке «Спавнер → Враг → Цель»
- Движение целей по заданному маршруту (waypoints)
- Использование корутин для отложенного спавна (`StartCoroutine`)
